# TNT Classic Movie Channel

A synchronized HBO-style live movie channel centered on the classic TNT / Turner movie-library feel.

## Live channel

https://www-infinity4.github.io/TNT/

## Schedule behavior

- 24-hour synchronized movie schedule
- New deterministic lineup at 12:00 AM in each viewer's local time
- Refreshing during the same day preserves that day's rotation
- Start over, rewind 30 seconds, and rejoin live
- Three-minute commercial-break structure between movie segments
- Shared Infinity channel hamburger and directory
- Social preview artwork and share metadata

## Turner Vault

The page also keeps a classic-film vault for the Turner-era identity. Titles can be promoted into the playable live rotation as suitable official embeddable sources are connected.
